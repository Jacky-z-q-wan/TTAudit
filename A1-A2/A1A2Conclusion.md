# TTAudit · A1→A2 研究总结与结论

> 性质：内部研究留档，用于向导师汇报与指导后续选题。
> 更新时间：2026-09-08。数据来源：`outputs/` 下各探针实跑结果（3-seed 均值已标注）。
> 一句话概括：**A1（单客户端 TTA 的“最终模型”泄露审计）已用完整负结果链关闭，研究主线转入 A2（多客户端协作 TTA 的“中间消息”泄露边界）；A2 尚未跑第一个可行性实验，属于下一步。**

---

## 1. 来龙去脉：我们为什么走到隐私这条线上

1. 最初课题是 **C-cubed（云—边 TTA 中尾类/最差类的提升）**。与导师讨论后被告知：尾类提升不是云边场景的特有问题，任何数据分布都会有尾类，研究“不一定只能在云边做”，立意不够好。
2. 导师建议转向 **云边传递过程中的隐私保护**：不直接传原始数据，而是传“处理过的数据 / 提前算好的中间状态”，使外部入侵难以还原隐私。
3. 我们把这个想法扩成了两条可执行的研究线：
   - **A1：单客户端 TTA 隐私审计**——攻击者事后拿到“适应后的最终模型快照”，能否猜出某张图在不在适应流里（成员推断）。等价于回答：本地模型在线适应一遍之后，模型本身会不会“记住”个体。
   - **A2：多客户端 / 联邦式协作 TTA 的中间消息隐私**——多个客户端各自持有模型副本与私有无标注数据流，通过中心服务器交换 BN 统计、类原型、压缩特征、提示向量等中间消息来协同适应；此时隐私风险发生在“传出去的消息”上，而不是“最终模型”上。
4. A1 用 Pilot + P1–P4 四条探针跑完并关闭；其负结果反而构成了 A2 的动机基础（详见 §3）。

## 2. A1 的威胁模型与固定设置（所有探针共用）

| 项 | 值 |
|---|---|
| 数据集 / 扰动 | CIFAR-100-C / `gaussian_noise`，severity 5 |
| 模型 | CIFAR-100 干净训练集训出的 ResNet-18（源模型） |
| 适应方法 | Tent（BN+affine，熵最小化）；个别探针做 BN-only / BufTTA / 裁剪 |
| 成员流（私有） | 2000 张（Pilot/P1/P2/P3）；P4 改为不均衡成员流（见 §3.5） |
| 非成员集 | 2000 张，同扰动同 severity，与成员互不重叠 |
| 公开评测流 | 1000 张，测效用 Top-1，不参与适应与攻击 |
| 攻击 | 成员推断 MIA，打分 = 熵取负 / 置信度 / 真实标签 CE（诊断用） |
| 指标 | 攻击 AUC（0.5=瞎猜，1=全中），辅助报 Top-1（防“坍缩假象”） |
| 攻击者能力 | 白盒拿到适应后模型权重（不含训练中的记忆库内容） |

关键设计纪律：成员与非成员必须来自同一扰动同一强度（绝不用干净图当非成员）；每遍/每配置从同一个源模型独立开始；AUC 高时必须同时看 Top-1 是否崩。

## 3. A1 探针与实验结果（按时间顺序）

### 3.1 Pilot（2026-09-07 起）——单遍正常适应漏不漏？
- Source：ent AUC 0.5023 / conf 0.5029 / Top-1 11.7（负对照≈0.5，说明尺子准）。
- Tent（1 遍）：ent AUC 0.5096 / conf 0.5126 / Top-1 41.2（适应有效但几乎不泄露）。
- 判读：**正常单遍在线 TTA 在“最终模型”威胁模型下几乎不泄露个体**（AUC≈0.51，贴近随机 0.50）。
- 悬念：会不会只是“每张只过一次、还来不及记住”？→ 引出 P1。

### 3.2 P1——多遍曝光：泄露是曝光次数的函数
- Tent 重复 2 / 5 / 10 遍（每遍从源模型重启，各遍独立）：
  - 2 遍：ent 0.5238 / Top-1 44.4
  - 5 遍：ent 0.5506 / Top-1 49.4
  - 10 遍：ent 0.5895 / conf 0.5915 / Top-1 49.7
- 判读：**泄露确实出现，且随“对个体的反复拟合”单调上升**；正常单遍形态不泄露，泄露需要过拟合个体。
- 新问题：这个泄露是“看多了就记住”的平凡效应，还是特定机制（组件）造成的？→ 引出 P2 / P3。

### 3.3 P2——带记忆库回放（BufTTA）漏不漏？
- BufTTA = Tent + 高置信样本记忆库（tau=0.7，M=500，每 16 个流 batch 回放一次，实际回放 2 次），结束后**丢弃记忆库只留权重**。
- 结果：ent AUC 0.5104 / conf 0.5138 / Top-1 40.8。
- 判读：**弱回放下记忆库方法也不泄露**（与 Tent 无异），泄漏并不来自“存了样本”这件事本身。

### 3.4 P3——可行性门槛：组件不对称性
在“10 遍反复曝光”这个已知会泄露的平台上，逐项拆组件：

| 系统 | ent AUC | Top-1 | 含义 |
|---|---:|---:|---|
| Source（锚） | 0.5023 | 11.7 | 无适应 |
| Tent 1 遍（锚） | 0.5096 | 41.2 | 单遍不泄露 |
| Tent 10 遍 BN+affine（锚） | 0.5895 | 49.7 | 反复曝光+学 affine → 泄露 |
| **Tent 10 遍 BN-only（只更新运行统计）** | **0.4957** | 36.8 | 只动 BN 统计不泄露 |
| BufTTA 强回放（每流 batch 回放≈32 次） | 0.5183 | 42.7 | 记忆库强回放仍几乎不泄露 |
| Tent 10 遍 + 梯度裁剪 C=1 | 0.5032 | 38.6 | 裁剪能压住泄露，但效用从 49.7 掉到 38.6 |

- 判读（关键负结果链）：
  - **纯 BN 运行统计怎么反复看都不泄露**（0.4957）；
  - 强记忆库回放也不泄露（0.5183）；
  - **泄露的必要组合 = “可学习的 affine 参数更新 + 反复曝光（过拟合个体）”**；
  - 裁剪能把 AUC 压回 0.50，但以明显效用损失为代价 → “便宜防护”不成立，DP 式逐样本裁剪不是免费的。
- 意义：泄露不是“曝光次数”的平凡函数，而是特定机制（affine 学习）把个体焊进权重造成的 → 有“机制不对称性”可写；但最后一次机会在稀有类（匿名集）效应上。

### 3.5 P4——稀有类 / 匿名集“死心实验”（A1 终点，3 seeds）
把成员流改成不均衡：尾类 30 类 × 每类 2 张、中类 30 × 10、头类 40 × 40（共 1960），按真实类成员数 n_c 分桶算成员推断 AUC。

| 配置 | tail(1~3) AUC | mid(10) AUC | head(40) AUC | tail−head | Top-1 |
|---|---:|---:|---:|---:|---:|
| Tent 10 遍 BN+affine | 0.6380±0.0049 | 0.5844±0.0245 | 0.5844±0.0064 | 0.0536±0.0079 | 49.83±0.17 |
| Tent 1 遍 BN+affine | 0.5331±0.0548 | 0.5027±0.0217 | 0.5021±0.0030 | 0.0311±0.0521 | 38.20±0.42 |
| Tent 10 遍 BN-only | 0.5135±0.0603 | 0.4928±0.0115 | 0.4967±0.0068 | 0.0168±0.0565 | 36.53±0.17 |

- 判据预置：tail≥0.65 且 tail−head≥0.10 才“救活”；实测 tail=0.638、tail−head=0.054 → **未过门槛**。
- 判读：稀有类在“最终模型快照”里确实表现出一定集中趋势（0.638 > 0.584），但强度弱（差 0.05 量级），不足以撑起一篇论文；Tent-1 与 BN-only 的尾效应更弱或不稳。A1 线按预定规则**关闭，不再追加“再试一次”实验**。

## 4. A1 结论：我们到底证明了什么（负结果 + 可复用机制结论）

1. 在“攻击者事后拿到最终模型快照”的威胁模型下，**正常单遍在线 TTA 几乎不泄露个体**（AUC≈0.51）。
2. 泄露强度是**“曝光次数 × 可学习 affine 参数”**的函数；纯 BN 统计、记忆库回放都不产生可测泄露；梯度裁剪可压泄露但伤效用。
3. 稀有类在最终模型上的泄露集中度弱（tail−head≈0.05），匿名集效应在“模型内部记忆”这条通道上不显著。
4. **推论（A2 的动机）**：个体信息很难被“焊进”适应后的模型权重里；那么如果隐私真的会漏，唯一可能的高风险通道就是**协作过程中必须跨信任边界传输的逐条中间消息**（统计量、类原型、压缩特征、提示向量）。当某条消息聚合的样本数 n_c 很小（如 1~2 张/类）时，消息本身就退化成“近似单样本”，无需攻破模型即可读取。→ 威胁重定位：**从“适应后的模型”转向“跨端传输的消息”。**

## 5. A2：下一步主线——多客户端协作 TTA 的中间消息隐私

### 5.1 为什么现在文献是空的（机会点）
- 联邦 / 协作 TTA（Latte、FedCTTA、BPFedCTTA、COTE、FedPAT、pFedBBN 等）都**宣称“不传原始数据即天然安全”，但全部没有给出攻击者模型、泄露度量或攻击套件**，“隐私安全”只是口头承诺。
- DP-TTA（单机 TTA + 差分隐私）给出了参数更新的理论隐私上界，但**不回答“多端协作该传什么消息、传出去究竟泄露多少个体信息”**。
- LLM 侧已出现“经验隐私保护评测基准”（ICLR 2026 Oral），但 TTA / 协作 TTA 侧还没有对标的实证基准 → 立范式空间存在。

### 5.2 威胁模型与攻击类型
- 攻击者：诚实但好奇的中心服务器，或可窃听信道的第三方；掌握公开模型、背景数据与整条消息流，接触不到任何客户端原始数据。
- 攻击目标：重构（从消息还原图像）、类级披露（某类是否/被多少个体贡献）、成员推断（某个体是否参与某条消息）、属性推断。
- 消息“旋钮”空间：聚合样本数 n_c、特征投影维度 d、注入噪声 σ（对应高斯机制 / 差分隐私预算）。

### 5.3 可证伪假设（A2 版）
- **H1（载体支配性）**：存在“消息载体 × 旋钮取值”的组合，在同等或更少上传字节下，效用不弱于现有方案而泄露更低（先扫地图，找支配前沿）。
- **H2（消息层匿名集效应）**：逐条消息的泄露强度随其聚合样本数 n_c 减小而系统性增大（A1 在“模型内部”只测到≈0.05，消息层预期放大一个量级）；n_c 很小时少数类 / 稀有类个体风险最高。
- **H3（类感知预算分配）**：在累计隐私/字节预算约束下，按消息 n_c 分配保护强度（稀有类更强扰动、头部类保留信息）显著优于对所有消息一视同仁。
- **H4（基准可交付性）**：可以交付统一威胁模型 + 攻击实现 + 泄露指标 + 基线方法的可复现评测基准，并实测现有联邦 TTA 方法的真实泄露水平。

### 5.4 A2 Pilot #1（生死线，尚未执行，等待 go/no-go）
- 目的：先验证“协作是否真的买得到精度”——这是整个 A2 立论的前提，不行一切免谈。
- 设置：CIFAR-100-C 单一扰动流切成 K≈4–8 个非独立同分布（按域/类分布错开）客户端切片，各客户端持同一全局模型副本；三线对比：
  - Local-only：各端独立本地适应，不聚合；
  - NoRaw：只交换统计/原型等中间消息后聚合（无原图）；
  - Raw：集中式原图训练（上界）。
- 过线判据：NoRaw 相对 Local-only 的增益 ≥ Raw 相对 Local-only 增益的 60%，或 NoRaw 与 Raw 最终差距 ≤5 个百分点 → “不传原图也能帮到协作”成立。
- 复用点：同一切分哲学、同一 MIA 打分管线、同一源模型与 CIFAR-100-C 数据，直接在前述 pipeline 上扩展多客户端模拟。

## 6. 后续猜想与备选方向（供讨论，非承诺）

1. **“隐私到底空不空旷”的判断**：单机“最终模型”通道已被我们证伪（空旷但无货）；真正的空旷地带在**协作消息的实证泄露、攻击套件与基准**——现有工作只宣称不安全/安全，没人系统量过。若 A2 Pilot #1 过线且 H2 出现数量级放大，就是一整块新地。
2. **兜底路径**：即便消息层泄露弱于预期，H4 的评测基准本身可独立成文（Datasets & Benchmarks 通道）；A1 的“组件不对称性”负结果链也可单独写成机制审计小论文，研究不会全损。
3. **跨域猜想（去噪/复原 × TTA 隐私）**：“复原/去噪任务 × TTA”本身已是拥挤方向（多篇近年工作），但“**自适应复原 × 消息隐私混淆**”与“**复原场景下的中间表示泄露边界**”确属空白；代价高（成对数据集、大模型/扩散、重训练重）。建议先让 A2 Pilot #1 出结果，再评估跨域迁移成本，不要现在分心。
4. **工程/叙事猜想**：A1 的完整实证链（单遍不泄露 → 曝光次数效应 → 组件不对称 → 稀有类弱效应）可以直接作为 A2 论文 intro 的“威胁重定位”证据，避免从零编动机。
